## امکانات

### سرور VPN
| امکان | توضیحات |
|-------|---------|
| **L2TP/IPSec PSK** | سازگار با ویندوز، اندروید، iOS و مک — بدون نیاز به اپ جانبی |
| **strongSwan** | پروپوزال‌های curve25519 و modp1024 برای سازگاری حداکثری (شامل iOS 17+) |
| **پول 192.168.43.x** | تا ۲۴۰ کاربر همزمان |
| **XAuth (اختیاری)** | کانفیگ Cisco IPsec برای کلاینت‌های قدیمی |
| **NAT + MSS Clamp** | اینترنت کامل با MTU بهینه |

### مدیریت کاربران
| امکان | توضیحات |
|-------|---------|
| **انقضای خودکار** | تاریخ و ساعت دقیق + قطع خودکار کاربر منقضی‌شده |
| **محدودیت حجم** | سهم GB دلخواه برای هر کاربر + شمارش لحظه‌ای ترافیک (هر ۳۰ ثانیه) |
| **DNS اختصاصی** | DNS جداگانه برای هر کاربر (شکن، الکترو، 403...) با ریدایرکت شفاف |
| **کد کاربر** | صفحه وضعیت شخصی برای هر کاربر — بدون نیاز به لاگین |
| **قطع فوری** | تغییر رمز یا حذف کاربر = قطع آنی اتصال |

### پنل وب
| امکان | توضیحات |
|-------|---------|
| **دوزبانه** | فارسی (RTL) / انگلیسی (LTR) با یک کلیک |
| **تم تاریک/روشن** | تم سایبرپانک نئونی + تم لایت مینیمال |
| **سایدبار** | منوی کشویی — داشبورد / کاربران / تنظیمات |
| **داشبورد زنده** | نمودار مصرف ۷ روزه، مصرف‌کننده‌های برتر، ظرفیت سیستم |
| **صفحه تنظیمات** | تغییر رمز ادمین، PSK، DNS پیش‌فرض، پورت پنل — همه از خود پنل |
| **دانلود بکاپ** | بکاپ کامل با یک کلیک (کاربران + تنظیمات) |
| **آپدیت خودکار** | دکمه آپدیت، آخرین نسخه را از گیت‌هاب در چند ثانیه می‌گیرد |
| **آیکون‌های نئونی** | ست آیکون گرادیانتی اختصاصی + افکت گوی موس |

## نصب سریع

### روش تعاملی (پیشنهادی)

روی سرور اوبونتو خود، با دسترسی root یا sudo:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/3OUTHBOY/Panel-L2TP/main/install.sh)
```

نصب‌کننده چند سؤال می‌پرسد:
- نام کاربری و رمز عبور ادمین پنل
- **پورت پنل** (دلخواه، پیش‌فرض 8080)
- کلید PSK (پیش‌فرض: تولید خودکار امن)
- آی‌پی مجاز برای دسترسی به پنل (اختیاری)
- منطقه زمانی و فایروال

پس از ~۲ دقیقه، اطلاعات اتصال نمایش داده می‌شود:

```
=====================================================
      3OUTHBOY PANEL — Installation complete!
=====================================================
 Panel URL       : http://YOUR_SERVER_IP:8080
 Admin username  : admin
 Admin password  : xK9mP2nQ8rT4
 IPSec PSK       : aB3cD4eF5gH6iJ7kL8mN
=====================================================
```

### روش غیرتعاملی (برای اتوماسیون و cloud-init)

```bash
bash <(curl -Ls https://raw.githubusercontent.com/3OUTHBOY/Panel-L2TP/main/install.sh) \
  --user admin \
  --pass MyStrongPass123 \
  --port 9443 \
  --psk MySecretPSK \
  --no-ufw
```

| فلگ | پیش‌فرض | توضیح |
|-----|---------|-------|
| `--user` | `admin` | نام کاربری ادمین |
| `--pass` | رندوم | رمز عبور ادمین |
| `--port` | `8080` | پورت پنل (انتخاب دلخواه) |
| `--psk` | رندوم | کلید مشترک IPSec |
| `--admin-ip` | خالی | آی‌پی مجاز پنل (خالی = بدون محدودیت) |
| `--no-ufw` | فعال | نصب نشدن فایروال UFW |

> از `bash <(curl ...)` به‌جای `curl | bash` استفاده می‌شود تا سوالات تعاملی درست کار کنند.

## اتصال کاربران

### ویندوز
1. **Settings → Network & Internet → VPN → Add a VPN connection**
2. VPN provider: `Windows (built-in)`
3. نوع VPN: **`L2TP/IPsec with pre-shared key`**
4. Pre-shared key: از پنل کپی کنید
5. نام کاربری / رمز: از پنل

> اگر خطای **809** گرفتید: پورت‌های UDP 500 و 4500 را در فایروال ویندوز و روتر باز کنید.

### اندروید
1. **Settings → Network & Internet → VPN → +**
2. نوع: **`L2TP/IPSec PSK`**
3. آدرس سرور: IP سرور
4. IPSec pre-shared key: از پنل
5. نام کاربری / رمز: از پنل

### iOS / مک
1. **Settings → VPN → Add VPN Configuration**
2. نوع: **`L2TP`**
3. سرور: IP سرور
4. اکانت: نام کاربری / رمز: رمز عبور
5. Secret: از پنل

> iOS 17+ به‌صورت خودکار پروپوزال‌های curve25519/modp1024 را مذاکره می‌کند — نیازی به تنظیم خاص نیست.

### لینوکس (NetworkManager)

```bash
nmcli connection add type vpn vpn-type l2tp \
  con-name "MyVPN" vpn.data "gateway=SERVER_IP, ipsec-enabled=yes, ipsec-psk=YOUR_PSK" \
  vpn.secrets "username=USER, password=PASS"
```

## مدیریت پنل

### ناوبری

پنل از منوی کشویی سایدبار (دکمه همبرگر) با سه بخش استفاده می‌کند: **داشبورد**، **کاربران** و **تنظیمات**.

### داشبورد

- **کارت‌های آمار**: آدرس سرور، PSK (نمایش/کپی)، کاربران فعال، نشست‌ها، مصرف کل
- **نمودار مصرف ۷ روزه** با تولتیپ
- **مصرف‌کننده‌های برتر** با مدال طلا/نقره/برنز
- **نوار ظرفیت سیستم** (اسلات‌های IP از ۲۴۰)
- **وضعیت سرویس‌ها**: IPSec / L2TP / NAT — سبز = فعال، قرمز = مشکل

### کاربران

- **افزودن کاربر**: نام کاربری، رمز (خالی = خودکار)، اعتبار (روز)، محدودیت حجم (GB)، DNS ۱ و ۲، تاریخ دقیق انقضا
- **جدول کاربران**: نمایش/کپی رمز، انقضا، زمان باقی‌مانده، نوار حجم، DNS اختصاصی، کد کاربر، وضعیت، عملیات

### عملیات هر کاربر

| دکمه | عملکرد |
|------|--------|
| **تمدید + روز** | اضافه کردن روز به انقضای کاربر |
| **ویرایش** | رمز، تاریخ انقضا، حجم، DNS، کد کاربر |
| **ریست حجم** | صفر کردن شمارنده مصرف |
| **کد جدید** | تولید کد رندوم جدید (لینک قبلی باطل می‌شود) |
| **حذف** | حذف کامل کاربر + قطع فوری |

### لینک وضعیت کاربر

هر کاربر یک کد یکتا دارد — این لینک را به او بدهید:

```
http://SERVER_IP:PORT/u/USER_KEY
```

کاربر بدون لاگین می‌بیند: اطلاعات اتصال، گیج دایره‌ای حجم، **شمارش معکوس زنده**، وضعیت.

> این لینک شامل رمز VPN است — فقط به خود کاربر بدهید!

### تنظیمات

همه‌چیز از خود پنل — بدون نیاز به SSH:

| تنظیم | عملکرد |
|--------|---------|
| **حساب ادمین** | تغییر نام کاربری و رمز پنل |
| **PSK** | تغییر کلید IPSec (ریستارت خودکار سرویس) |
| **DNS پیش‌فرض** | DNS سرور برای کاربران بدون DNS اختصاصی |
| **پورت پنل** | تغییر پورت (فایروال + ریدایرکت خودکار) |
| **بکاپ** | دانلود همه کاربران و تنظیمات با یک کلیک |

### عملیات سریع (هدر)

- **همگام‌سازی** / **آپدیت پنل** (از گیت‌هاب، ~۱۵ ثانیه) / **ریستارت VPN** / **ریستارت پنل**

### زبان و تم

- **FA / EN**: تغییر زبان فارسی ⇄ انگلیسی
- **DARK / LIGHT**: تغییر تم تاریک ⇄ روشن (در مرورگر ذخیره می‌شود)

## معماری سیستم

```
┌─────────────────────────────────────────────────┐
│                     Client                       │
│         (Windows / Android / iOS / Linux)        │
└───────────────────┬─────────────────────────────┘
                    │ UDP 500/4500 (IPSec) + 1701 (L2TP)
┌───────────────────▼─────────────────────────────┐
│                  strongSwan                      │
│         (IKEv1 PSK, transport mode)             │
└───────────────────┬─────────────────────────────┘
┌───────────────────▼─────────────────────────────┐
│                   xl2tpd  →  pppd                │
│      (CHAP auth, per-user DNS, counters)        │
└───────────────────┬─────────────────────────────┘
┌───────────────────▼─────────────────────────────┐
│              iptables NAT + DNS DNAT            │
└─────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────┐
│        Web Panel (Flask + gunicorn + SQLite)     │
│                 panel/ in this repo              │
└─────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────┐
│      sync_users.py (systemd timer, every 30s)    │
│   sync users · enforce expiry/quota · DNS rules  │
└─────────────────────────────────────────────────┘
```

### فایل‌ها و مسیرها

| مسیر | توضیح |
|------|-------|
| `/opt/l2tp-panel/` | دایرکتوری اصلی پنل |
| `/opt/l2tp-panel/users.db` | دیتابیس SQLite کاربران (**بکاپ بگیرید!**) |
| `/opt/l2tp-panel/config.json` | تنظیمات (رمز ادمین، PSK) |
| `/etc/ipsec.conf` | کانفیگ strongSwan |
| `/etc/ppp/chap-secrets` | کاربران فعال (مدیریت خودکار) |
| `/run/l2tp-ifaces/` | شمارنده‌های ترافیک |

### سرویس‌های systemd

```bash
systemctl status l2tp-panel          # پنل وب
systemctl status strongswan-starter  # IPSec
systemctl status xl2tpd              # L2TP
systemctl status l2tp-nat            # NAT
```

### بکاپ

از خود پنل: **تنظیمات → دانلود بکاپ** — یا:

```bash
tar czf l2tp-backup-$(date +%F).tar.gz /opt/l2tp-panel/users.db /opt/l2tp-panel/config.json
```

## عیب‌یابی

### پنل بالا نمی‌آید

```bash
systemctl status l2tp-panel
journalctl -u l2tp-panel -n 30 --no-pager
```

### کاربر وصل نمی‌شود

```bash
journalctl -u strongswan-starter -u xl2tpd -f
```

| پیام لاگ | مشکل | راه‌حل |
|----------|------|--------|
| هیچ پیامی نمی‌آید | فایروال یا فیلترینگ ISP | باز کردن پورت‌ها؛ تست با اپراتور دیگر |
| `NO_PROPOSAL_CHOSEN` | عدم تطابق رمزنگاری | ثبت issue |
| `Authentication failed` | اطلاعات ورود اشتباه | کپی مجدد از پنل |
| بدون اینترنت | مشکل NAT | `systemctl restart l2tp-nat` |
| خطای 809 (ویندوز) | بسته بودن پورت‌ها | باز کردن UDP 500/4500 |

### نمایش داده نشدن مصرف حجم

```bash
ls /run/l2tp-ifaces/
python3 /opt/l2tp-panel/sync_users.py
```

> مصرف هر ~۳۰ ثانیه آپدیت می‌شود. مقادیر زیر ۱ گیگ به MB نمایش داده می‌شوند.

### کار نکردن DNS اختصاصی

کاربر باید **قطع و دوباره وصل شود**، سپس:

```bash
nslookup google.com
```

## حذف کامل

```bash
systemctl disable --now l2tp-panel l2tp-sync.timer l2tp-sync l2tp-nat strongswan-starter xl2tpd
rm -f /etc/systemd/system/l2tp-{panel,nat,sync.service,sync.timer}
rm -rf /opt/l2tp-panel
rm -f /etc/ppp/ip-{up,down}.d/90l2tp-panel
rm -rf /etc/ppp/dns-map /run/l2tp-{sessions,ifaces,peerip}
rm -f /usr/local/sbin/l2tp-nat.sh
apt-get remove -y strongswan* xl2tpd gunicorn python3-flask
systemctl daemon-reload
```

## سوالات متداول

**آیا رمزی در مخزن گیت‌هاب ذخیره شده؟**
خیر — رمز ادمین و PSK روی هر سرور موقع نصب به‌صورت رندوم تولید می‌شوند.

**اگر اسکریپت را دوباره اجرا کنم چه؟**
کانفیگ‌ها بازنویسی می‌شوند؛ دیتابیس کاربران حفظ می‌شود.

**چطور پنل را آپدیت کنم؟**
دکمه **آپدیت پنل** را بزنید — آخرین نسخه از پوشه `panel/` همین مخزن در ~۱۵ ثانیه دریافت می‌شود.

**چند کاربر همزمان؟**
تا ۲۴۰ کاربر (پول 192.168.43.10 تا 250).
